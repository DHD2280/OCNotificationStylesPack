# OC Notification Styles Pack

The notification styles for [Oxygen Customizer](https://github.com/DHD2280/Oxygen-Customizer), as a notification style pack.

It contains the 23 classic Oxygen Customizer styles (the old `NFN` overlays): Monet, Layers, Thin Outline, Bottom Outline, Neumorph, Stack, Side Stack, Outline, Leafy Outline, Lighty, Lighty v2, Neumorph Outline, Cyberponk, Cyberponk v2, Thread Line, Faded, Dumbbell, Semi Transparent, Pitch Black, Duoline, iOS, Transparent and Thin Outline Transparent.

## Use

1. Install the APK.
2. Open **Oxygen Customizer → Notification style packs**.
3. Pick a style. SystemUI restarts to apply it.

You don't need overlays, a Magisk module or a reboot.

## Make your own pack

To learn the pack format, see [OCNotificationStyleTemplate](https://github.com/DHD2280/OCNotificationStyleTemplate).

## Build

```
./gradlew :app:assembleRelease
```
